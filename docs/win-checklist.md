# 윈도우 설치 뒤 확인 목록

[맥 확인 목록](mac-checklist.md)처럼 "이 키를 누르면 이게 보여야 한다" 꼴로 적는다. 키는 키캡에 적힌 쿼티 글자 그대로 누른다.
개발 중에는 `tools\win\tip-dev.ps1 install`로 설치하고, 입력기는 Win+Space에서 **cssgsg**(ENG)를 고른다.
사람이 확인하는 것은 입력기가 앱·윈도우와 주고받는 부분(글자 넣기, 단축키, 등록과 해제)이다. "확인" 칸은 마지막으로 확인한 날과 환경이다.

| # | 단계 | 장소 | 할 일 | 보여야 하는 것 | 확인 |
|---|---|---|---|---|---|
| 1 | M3a | 메모장 | Win+Space로 cssgsg를 고르고 `j l w w i` | hello (Graphite. M3a는 조합 없이 바로 확정한다) | 2026-10-01, 25H2 VM |
| 2 | M3a | 메모장 | 글자를 몇 개 친 뒤 Ctrl+A, Ctrl+C, Ctrl+V, Ctrl+Z | 키캡(쿼티)대로 전체 선택·복사·붙여넣기·되돌리기 | 2026-10-01, 25H2 VM |
| 3 | M3a | 메모장 | Backspace, Enter, 방향키, Shift+`j` | 앞의 셋은 평소대로, Shift+`j`는 H | |
| 4 | M3a | PowerShell | `tip-dev.ps1 uninstall` 뒤 `status` | 등록·TSF 프로필·내 입력 목록·파일이 모두 False. HKCU의 CTF 키와 정렬 캐시에도 남지 않는다(쓰는 중이던 DLL은 다시 시작할 때 지워진다) | 2026-10-01, 25H2 VM |
| 5 | M3a | 윈도우 설정 | 시간 및 언어 → 언어 및 지역 | 영어(미국) 언어 기능이 없는 한국어 윈도우에서는 영어(미국)도 cssgsg도 목록에 없다(Win+Space에는 있다). 언어 추가로 영어(미국)를 넣으면 그 언어 옵션의 키보드에 cssgsg가 보일 것이다 | 앞 절반만 2026-10-01, 25H2 VM |
