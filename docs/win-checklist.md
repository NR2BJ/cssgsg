# 윈도우 설치 뒤 확인 목록

[맥 확인 목록](mac-checklist.md)처럼 "이 키를 누르면 이게 보여야 한다" 꼴로 적는다. 키는 키캡에 적힌 쿼티 글자 그대로 누른다.
개발 중에는 `tools\win\tip-dev.ps1 install`로 설치하고, 입력기는 Win+Space에서 **cssgsg**(ENG)를 고른다.
사람이 확인하는 것은 입력기가 앱·윈도우와 주고받는 부분(글자 넣기, 단축키, 등록과 해제)이다. "확인" 칸은 마지막으로 확인한 날과 환경이다.
