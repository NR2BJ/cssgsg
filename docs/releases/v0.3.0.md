## 새 기능: 한국어 한자 변환 (⌥Option + Return)

- 한글을 친 뒤 **Option+Return**을 누르면 커서 앞 한글에서 사전과 맞는 가장 긴 낱말이 바로 1번 후보로 바뀌고(밑줄 조합), 후보창이 뜬다.
  - 조합 중인 음절만이 아니라 **이미 확정된 앞 글자도 같이** 바꾼다(대한민 + 국 → 大韓民國). 커서를 옮겨 둔 낱말도 된다.
  - 글자를 **선택**해 두면 선택한 글을 바꾼다.
  - 후보창에 **짧은 구간 후보도 이어서** 나온다(大韓民國 다음에 民國, 그다음 國·局·菊 …). 고르는 후보가 곧 바꿀 구간이다. Shift+←→로 긴 낱말 ↔ 짧은 낱말 무리로 건너뛴다.
  - 후보 옆에 **뜻**이 흐리게 보인다(國 나라 국, 電氣 번개 전 · 기운 기). 격자에서는 고른 후보의 뜻이 아래 줄에 나온다.
- 조작은 일본어 후보창과 같다: Space·↓ 다음, ↑ 이전, Tab 격자, ←→ 페이지, 1~9 고르고 확정, Enter 확정, Esc·Backspace 원래대로(조합 중이던 음절은 다시 조합), 그 밖의 키는 확정하고 이어서 친다.
- **자음 하나 + Option+Return**은 기호표(MS IME와 같은 표): ㅁ → ※ ☆ ★ ○ ●, ㄱ → 전각 문장부호, ㅈ → ０１２ ⅰⅱⅲ, ㅇ → ⓐⓑⓒ …
- **고른 한자를 기억**해서 다음에 먼저 보인다(`~/Library/Application Support/cssgsg/hanja-learning.tsv`).
- 사전은 libhangul의 한자 사전(30만 항목, BSD-3)이다. 낱말 순서는 사전 순서라 처음에는 드문 낱말이 앞에 올 수 있다(대한 → 大寒이 大韓보다 앞). 한 번 고르면 그다음부터 앞에 온다.

## 앱마다 다를 수 있는 것

앞 글자를 끌어오려면 앱이 바꿔 넣기(replacementRange)를 받아 줘야 한다.
- 앱이 커서 앞 글자를 알려 주지 않으면(Chrome 계열은 조합 중에 알려 주지 않는다) 입력기가 **방금 이어서 친 한글**을 기억해 쓴다.
- 조합 글자 자리를 알려 주지 않는 앱에서는 **조합 중인 음절만** 바꾼다. 선택을 읽어 주지 않는 앱에서는 선택을 바꾸지 않는다.
- 어떤 앱에서 "대한민大韓民國"처럼 글자가 겹치거나 앞 글자가 사라지면 앱 이름을 알려 주면 된다([확인 목록](https://github.com/NR2BJ/cssgsg/blob/main/docs/mac-checklist.md) 18~22번).
