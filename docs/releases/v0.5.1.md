## 0.5.0 확인 결과를 반영했다

### 단축키

- **조합 단축키도 왼쪽·오른쪽 수식키를 가린다**(NRIME와 같다). 기본 한자 키는 **왼쪽 Option + Return**이다. 오른쪽 Option + Return은 한자가 아니다(조합을 확정하고 앱으로 간다). 녹화하면 "왼쪽 Control + Return"처럼 누른 쪽이 적힌다.
- **Control 조합을 한자 키로 쓰면 전송되던 것을 고쳤다.** Control을 누르는 순간 조합을 확정하던 동작이 먼저 돌아서, Control + Return이 Discord에 그대로 가서 메시지가 전송됐다. 이제 한자 키에 쓰는 Control이면 조합을 남겨 두고 한자로 바꾼다.
- **⌘ 조합은 녹화하지 않는다.** Chrome·Discord 같은 앱은 ⌘+키를 입력기에 보내지 않아서, 앱에 따라 되다 말다 한다. ⌘ 탭은 된다.
- **빠른 탭 전환 보정은 보류했다**(설정에서 뺐다). 쌍자음이나 Shift 대문자를 빠르게 칠 때 전환으로 잘못 볼 수 있어서 다시 설계한다.

### 일본어

- **↓는 변환 키가 아니다.** 가나를 치는 중에 ↓를 누르면 다른 화살표처럼 확정하고 앱으로 간다. 변환 중(후보창)의 ↑↓는 그대로 후보 이동이다.
- **공백은 반각 / 전각 중에서 고른다.** 가나를 치는 중의 Space는 변환이라 해당하지 않는다.
- **¥를 끄면 반각 `\`** 가 나온다(경로·코드용). 0.5.0은 전각 ＼가 나왔는데, 전각 ＼는 쓸 데가 거의 없다.
- 개인 사전 읽기에 작은 가나(ゃ ゅ ょ っ ぁ …)와 장음 부호(ー)를 써도 변환에 나온다(시험함).

### 그 밖에

- **입력기를 켜면 한국어로 시작한다.**
- **조합 중 Shift+Enter 줄바꿈 대기는 조정값 하나로 바꿨다**(−50 ~ +50ms, 기본 0). 기본 대기는 앱 종류마다 따로 있다(더하지 않는다): Electron 앱 15ms, Codex처럼 Enter를 전송으로 받는 앱 120ms. 설정 창에 지금 대기가 보인다. 0.5.0에서 바꾼 값은 조정값으로 옮겨진다.
- **배열 학습 탭을 기다림 없이 연다**(설정 앱이 뜰 때 미리 읽어 둔다).
- 모드 표시(G · ㅊ · 月)의 글자를 상자 가운데에 놓았다. 모니터 높이가 서로 다를 때 커서 자리 계산이 위아래로 어긋날 수 있던 것을 고쳤다. 표시 자리가 어긋나는 앱이 있으면 알려 달라(개발자 기록에 자리를 남긴다).
