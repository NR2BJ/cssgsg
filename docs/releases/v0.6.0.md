## Mozc가 입력기와 따로 업데이트됩니다

- 일본어 한자 변환 엔진(Mozc)을 입력기 업데이트 없이 새 버전으로 바꿀 수 있게 했습니다(NRIME 1.0.12와 같은 방식).
- GitHub가 매주 upstream Mozc를 확인해, 버전이나 사전 데이터가 바뀌었으면 새 엔진을 빌드하고 시험한 뒤 올립니다.
- 입력기는 시작하고 5분 뒤, 그다음은 하루에 한 번 새 엔진을 확인해 내려받습니다. 받은 파일은 GitHub의 해시와 묶음 안의 파일별 해시가 모두 맞을 때만 쓰고, 다음에 입력기가 시작될 때부터 적용됩니다.
- **설정 앱 → 일본어 → 변환 엔진 (Mozc)** 에서 지금 쓰는 버전을 보고, "지금 확인"과 "지금 적용"(입력기가 곧바로 다시 시작)을 누를 수 있습니다.
- 받은 엔진이 읽히지 않거나, 읽다가 입력기가 멈추거나, 짧은 시간에 여러 번 비정상 종료되면 그 엔진은 다시 쓰지 않고 앱에 들어 있는 엔진으로 돌아갑니다.
- 변환 학습과 개인 사전은 엔진이 바뀌어도 그대로 남습니다.

## 줄바꿈 대기를 없앴습니다

- 조합 중 Shift+Enter의 줄바꿈 대기(Electron 15ms, Codex 120ms)와 설정 앱의 대기 항목을 없앴습니다. 줄바꿈은 기다리지 않고 바로 들어갑니다.
- 두 값은 macOS가 권한 없이 보낸 키를 조용히 버리던 때 정한 값이었고, 권한이 있으면 기다리지 않아도 늘 제대로 들어갔습니다(NRIME에서 Discord 9/9, Codex 11/11 확인).
- 설정 파일에 남아 있는 옛 대기 값은 읽고 무시합니다.

## 입력기 권한을 더 확실하게 확인합니다

- 권한 상태를 입력기가 활성화될 때마다(1분에 한 번까지) 다시 확인합니다. 입력기가 켜진 뒤에 허용한 권한도 다시 시작 없이 반영됩니다.
- 입력기가 먼저 권한 창을 띄우지 않습니다. **설정 앱 → 정보 → 입력기 권한**에서 상태와 마지막 확인 시각을 보고, "다시 확인 / 권한 요청"과 "시스템 설정 열기"를 누를 수 있습니다.
- 켜져 있는데도 "꺼짐"으로 표시되면 시스템 설정의 목록에서 cssgsg를 지운 뒤(−) 다시 추가해 주세요.

## 그 밖의 변경

- 모드 표시(HUD) 위치를 찾을 때 앱에 먼저 묻고, 손쉬운 사용(AX)은 마지막에만 씁니다. Chrome·Electron·Firefox를 무거운 손쉬운 사용 모드로 바꾸지 않습니다.
- 베타 채널이 GitHub 릴리스 목록을 더 넉넉히(100개) 읽습니다. Mozc 엔진 릴리스는 앱 업데이트로 표시되지 않습니다.
