## 바뀐 것 (일본어 변환 후보창, NRIME와 같게)

- **Space를 누르면 바로 후보창이 뜬다.** 글자는 1번 후보로 바뀐 채 조합 중(밑줄)으로 남는다.
- **Tab으로 후보창을 격자로 펼친다**(5열 × 6행). 화살표로 칸을 옮기고, 다시 Tab이면 목록으로 돌아온다.
- **후보창 아래에 페이지 번호**(예: 2/5)가 보인다(후보가 한 페이지를 넘을 때).
- 목록에서 ←→: 문절이 하나면 페이지를 넘기고, 여럿이면 문절을 옮긴다. Shift+←→는 문절 길이.
- Space·↓는 다음 후보, ↑는 이전 후보(끝에서 처음으로 돈다). PageUp/PageDown은 페이지. 1~9는 지금 페이지에서 골라 바로 확정.
