## 옛 Win32 앱에서 글자가 두 번씩 들어가던 문제

- 메모장(옛 판)처럼 IMM32로 입력기를 쓰는 Win32 앱에서 키가 두 번씩 들어가 글자가 깨지던 것을 고쳤습니다(예: "안녕하세요"가 "ㅇㄴㄴㄴㄴ…"로). 0.1.0과 0.2.0에 있던 문제입니다. 브라우저, VS Code, 디스코드처럼 TSF를 바로 쓰는 앱은 원래 괜찮았습니다.
- 같은 앱들에서 잠깐 쉬었다가 Shift를 톡 치면 오래 누른 것으로 보여 모드가 바뀌지 않을 수 있던 것도 고쳤습니다.
- 그 밖에는 0.2.0과 같습니다(Mozc 엔진 따로 업데이트, 작업 표시줄 아이콘 메뉴 등).

## 업데이트

- cssgsg 설정 → 정보 탭 → 지금 확인 → 설치. 받은 파일이 아래 SHA-256과 같을 때만 설치합니다(관리자 권한 창이 한 번 뜹니다).
- 이미 열려 있던 앱은 다시 열면 고친 입력기를 씁니다.

## 설치와 지우기

- 처음 설치: 아래 cssgsg-setup.exe를 받아 실행한 뒤 Win+Space로 cssgsg(ENG)를 고릅니다.
- 코드 서명이 없습니다. 스마트 앱 컨트롤(Windows 보안 → 앱 및 브라우저 컨트롤)이 켜져 있으면 입력기가 뜨지 않습니다. SmartScreen이 막으면 "추가 정보 → 실행"을 누릅니다.
- 엄격한 커널 안티치트를 쓰는 게임(발로란트, 리그 오브 레전드, FACEIT 등)은 확인되기 전까지 켜기 전에 Win+Space로 Microsoft 한국어 입력기로 바꿔 두세요.
- 게임 안의 후보창(UILess)과 게임 모드는 아직 없습니다.
- 지우기: 설정 → 앱 → 설치된 앱 → cssgsg. 설정과 학습(%APPDATA%\cssgsg, %LOCALAPPDATA%\cssgsg)은 남습니다.
