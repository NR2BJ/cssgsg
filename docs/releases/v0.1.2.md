## 고친 것

- **입력 소스 목록에 cssgsg가 긴 ID로 보이던 문제.** 이름 파일(InfoPlist.strings)이 빠져서
  "com.cssgsg.inputmethod.app.en"으로 보였다. 이제 "cssgsg"로 보인다.
- **입력기가 스스로 입력 소스를 켜려던 코드를 없앴다.** macOS 27은 서드파티 입력기를 프로그램이 켜는 것을 받아들이지 않는다
  (성공이라고 답하지만 아무것도 저장하지 않는다). 대신 아직 추가하지 않았으면 cssgsg 메뉴에 "⚠︎ 입력 소스에 추가하기…"가 보이고,
  설치 뒤 처음 한 번 키보드 설정을 열어 준다.
- **앱 안 업데이트 뒤 앱이 다시 뜨지 않던 문제.** 설치 스크립트 안에서는 설치가 아직 진행 중이라 앱을 띄울 수 없었다.
  이제 설치가 끝난 뒤에 새 앱을 띄운다(0.1.2부터의 업데이트에 적용).

## 설치·업데이트

터미널에서 (관리자 암호를 묻는다):

```bash
curl -fL -o /tmp/cssgsg.pkg https://github.com/NR2BJ/cssgsg/releases/latest/download/cssgsg.pkg && sudo installer -pkg /tmp/cssgsg.pkg -target / && open -g "/Library/Input Methods/cssgsg.app"
```

0.1.1에서 메뉴로 업데이트하면 이번에는 앱이 다시 안 뜰 수 있다(0.1.1의 업데이트 코드라서). 위 명령으로 설치하면 바로 뜬다.

## 입력 소스에 추가 (처음 한 번)

시스템 설정 → 키보드 → 텍스트 입력 → 입력 소스 "편집…" → 왼쪽 아래 + → **영어** → cssgsg → 추가.
목록에 안 보이면 시스템 설정을 끝냈다(⌘Q) 다시 연다. 그래도 없으면 로그아웃했다 다시 로그인한다.
