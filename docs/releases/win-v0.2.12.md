## 모드 표시(G/ㅊ/月)를 뺐습니다

- 모드를 바꿀 때 커서 근처에 잠깐 뜨던 G/ㅊ/月 표시를 없앴습니다(맥 0.7.5와 같습니다). 모드는 작업 표시줄의 모드 아이콘에서 봅니다. Microsoft 한국어 입력기도 이런 표시를 띄우지 않습니다.
- 설정 앱 일반 탭의 "모드 표시" 칸도 없어졌습니다. 설정 파일에 남은 예전 값은 읽고 버립니다.

## 비밀번호 칸: 쿼티인 곳은 작업 표시줄에 Q

- 브라우저(Edge·Chrome·Firefox 등)의 비밀번호 칸은 지금처럼 모드와 상관없이 Graphite로 쳐집니다.
- 앱이 비밀번호 칸에서 입력기를 꺼 버리는 곳은 입력기에 키가 오지 않아 쿼티로 들어갑니다: 설정 앱·와이파이 암호 상자, 옛 Win32 프로그램의 비밀번호 칸, UAC, 잠금 화면. Microsoft 입력기를 포함한 모든 입력기가 같고, 입력기 밑에 Graphite를 까는 공식 방법도 없습니다.
- 이제 그런 칸(입력기가 꺼진 창)에 들어가면 작업 표시줄 모드 아이콘이 G/ㅊ/月 대신 흐린 **Q**로 바뀝니다. Q가 보이면 쿼티로 쳐집니다. 입력칸이 아닌 곳(바탕 화면, 파일 목록, 게임 플레이 화면)에서도 Q가 보이는데, 거기서도 키는 쿼티로 갑니다.
- 개발자 기록을 켜 두었을 때 비밀번호 칸에서 친 키가 기록에 남던 것을 막았습니다. 이제 비밀번호 칸에 들어왔다는 한 줄만 남습니다.

## 게임 안에서는 가짜 키 입력을 만들지 않습니다

- 오버워치처럼 후보창을 직접 그리는 게임 안에서는 cssgsg가 키 입력을 흉내 내지(SendInput) 않습니다. 매크로 도구와 닮은 동작이라 안티치트 쪽에서 오해할 여지를 없앴습니다. 입력기 때문에 계정이 정지됐다고 확인된 사례는 찾지 못했습니다(안티치트는 막을 뿐입니다).
- 그래서 게임 안에서는 일본어 모드에서 켠 Caps Lock(가타카나)이 다른 모드로 나가도 저절로 꺼지지 않습니다. 직접 한 번 눌러 주세요. 다른 앱에서는 지금처럼 꺼 줍니다.
- 발로란트·리그 오브 레전드·FACEIT처럼 커널 안티치트를 쓰는 게임은 지금처럼 켜기 전에 Microsoft 한국어 입력기로 바꿔 두세요.

## 업데이트

- cssgsg 설정 → 정보 탭 → 지금 확인 → 설치. 받은 파일이 아래 SHA-256과 같을 때만 설치합니다(관리자 권한 창이 한 번 뜹니다).
- 이미 열려 있던 앱과 게임은 다시 열면 새 입력기를 씁니다.

## 설치와 지우기

- 처음 설치: 아래 cssgsg-setup.exe를 받아 실행한 뒤 Win+Space로 한국어 cssgsg를 고릅니다.
- 코드 서명이 없습니다. 스마트 앱 컨트롤(Windows 보안 → 앱 및 브라우저 컨트롤)이 켜져 있으면 입력기가 뜨지 않습니다. SmartScreen이 막으면 "추가 정보 → 실행"을 누릅니다.
- 엄격한 커널 안티치트를 쓰는 게임(발로란트, 리그 오브 레전드, FACEIT 등)은 켜기 전에 Win+Space로 Microsoft 한국어 입력기로 바꿔 두세요. 윈도우는 고른 입력기만 앱에 불러들이므로 cssgsg가 게임에 들어가지 않습니다(게임 중에는 Win+Space를 누르지 마세요).
- 오른쪽 Alt·Ctrl을 보통 Alt·Ctrl로 쓰려면: 설정 → 시간 및 언어 → 언어 및 지역 → 한국어 옆 ⋯ → 언어 옵션 → 키보드 레이아웃 "레이아웃 변경" → 한글 키보드(101키) 종류 3 → 다시 시작.
- 지우기: 설정 → 앱 → 설치된 앱 → cssgsg. 설정과 학습(%APPDATA%\cssgsg, %LOCALAPPDATA%\cssgsg)은 남습니다.
