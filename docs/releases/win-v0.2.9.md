## 일본어 모드에서는 일본어 입력기가 됩니다

- 0.2.8에서 cssgsg를 한국어 입력기로 바꾼 뒤, 오버워치 채팅이나 메모장 같은 옛 Win32 앱에서 일본어(月)가 조합되지 않고 가나가 한 글자씩 그대로 확정되던 것을 고쳤습니다. 윈도우는 한국어 입력기에는 한 글자짜리 조합만 허락합니다(Microsoft 입력기는 언어마다 따로라 이 일이 없습니다).
- 이제 月 모드로 바꾸면 cssgsg가 스스로 일본어 입력기가 되고, 한국어·영어로 돌아오면 한국어 입력기로 돌아옵니다. 작업 표시줄의 언어 표시가 あ ↔ 한으로 바뀝니다. 일본어 쪽은 입력 목록에 넣지 않아서 Win+Space 목록에는 지금처럼 "한국어 cssgsg"만 보입니다.
- 오버워치에서 일본어는 Microsoft 일본어 입력기처럼 변환은 되고, 조합 중인 글자가 입력칸 맨 앞에 겹쳐 그려지는 것은 그대로입니다(Microsoft 일본어 입력기도 같아서 게임 쪽 한계로 봅니다).
- 조합 중에 한국어 ↔ 일본어를 바꿔도 글자가 두 번 들어가지 않습니다.
- 일본어 모드에서는 오른쪽 Alt·Ctrl이 보통 Alt·Ctrl입니다(일본어 배치).

## 오른쪽 Alt·Ctrl을 Alt·Ctrl로 쓰려면

- 한국어 입력기에서 오른쪽 Alt·Ctrl이 한/영·한자 키가 되는 것은 윈도우의 한국어 키보드 종류 설정 때문입니다. 설정 → 시간 및 언어 → 언어 및 지역 → 한국어 옆 ⋯ → 언어 옵션 → 키보드 레이아웃 "레이아웃 변경"에서 **한글 키보드(101키) 종류 3**을 고르고 다시 시작하면, 오른쪽 Alt·Ctrl이 보통 Alt·Ctrl이 됩니다.
- 그래도 cssgsg는 그대로입니다: Shift 톡으로 바꾸고, 한자는 오른쪽 Ctrl 톡입니다. Microsoft 한국어 입력기의 한/영은 Shift+Space가 됩니다.

## 업데이트

- cssgsg 설정 → 정보 탭 → 지금 확인 → 설치. 받은 파일이 아래 SHA-256과 같을 때만 설치합니다(관리자 권한 창이 한 번 뜹니다).
- 이미 열려 있던 앱과 게임은 다시 열면 새 입력기를 씁니다.

## 설치와 지우기

- 처음 설치: 아래 cssgsg-setup.exe를 받아 실행한 뒤 Win+Space로 한국어 cssgsg를 고릅니다.
- 코드 서명이 없습니다. 스마트 앱 컨트롤(Windows 보안 → 앱 및 브라우저 컨트롤)이 켜져 있으면 입력기가 뜨지 않습니다. SmartScreen이 막으면 "추가 정보 → 실행"을 누릅니다.
- 엄격한 커널 안티치트를 쓰는 게임(발로란트, 리그 오브 레전드, FACEIT 등)은 켜기 전에 Win+Space로 Microsoft 한국어 입력기로 바꿔 두세요. 윈도우는 고른 입력기만 앱에 불러들이므로 cssgsg가 게임에 들어가지 않습니다(게임 중에는 Win+Space를 누르지 마세요).
- 지우기: 설정 → 앱 → 설치된 앱 → cssgsg. 설정과 학습(%APPDATA%\cssgsg, %LOCALAPPDATA%\cssgsg)은 남습니다.
