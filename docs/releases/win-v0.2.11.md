## 조합 중에 한국어 → 일본어로 바꿀 때: Microsoft 입력기와 같게

- 0.2.10의 방식(조합 중이던 한글을 지웠다가 일본어로 바꾼 뒤 다시 넣기)을 되돌렸습니다. 오버워치에서 글자가 두 번 들어가는 것이 고쳐지지 않았습니다.
- 이제 조합 중이던 한글은 그 Shift 톡에서 평소처럼 확정되고, 일본어로 바꾸는 것은 그 키 처리가 끝난 뒤에 합니다. Win+Space나 언어 전환 단축키로 바꿀 때 윈도우가 하는 것과 같은 때입니다. 빠르게 쳐서 다음 키가 먼저 오면 그 키 앞에서 바꿉니다.
- 현재 버전 Microsoft 한국어 입력기도 오버워치에서 조합 중에 일본어로 바꾸면 글자가 두 번 들어갑니다("이전 버전" 입력기는 그렇지 않습니다). cssgsg는 게임마다 따로 맞추지 않고 Microsoft 입력기와 같은 동작을 따릅니다: 게임 쪽에서 Microsoft 입력기 문제를 고치면 cssgsg도 같이 고쳐지게요. 오버워치에서 확인이 필요합니다.
- 일본어 → 한국어도 같은 방식입니다.

## Win+Space의 "일본어 cssgsg"

- 0.2.10에서 숨겼던 일본어 cssgsg를 다른 입력기처럼 평범하게 등록합니다. 숨기기는 일본어를 처음 쓸 때 다시 생겨서 지켜지지 않았습니다.
- 일본어가 깔린 PC에서는 Win+Space에 "일본어 cssgsg"가 보입니다. 고를 필요는 없습니다: "한국어 cssgsg"를 고르면 月 모드에서 cssgsg가 스스로 일본어 입력기로 바뀝니다. 일본어를 깔지 않은 PC에는 생기지 않습니다.

## 업데이트

- cssgsg 설정 → 정보 탭 → 지금 확인 → 설치. 받은 파일이 아래 SHA-256과 같을 때만 설치합니다(관리자 권한 창이 한 번 뜹니다).
- 이미 열려 있던 앱과 게임은 다시 열면 새 입력기를 씁니다.

## 설치와 지우기

- 처음 설치: 아래 cssgsg-setup.exe를 받아 실행한 뒤 Win+Space로 한국어 cssgsg를 고릅니다.
- 코드 서명이 없습니다. 스마트 앱 컨트롤(Windows 보안 → 앱 및 브라우저 컨트롤)이 켜져 있으면 입력기가 뜨지 않습니다. SmartScreen이 막으면 "추가 정보 → 실행"을 누릅니다.
- 엄격한 커널 안티치트를 쓰는 게임(발로란트, 리그 오브 레전드, FACEIT 등)은 켜기 전에 Win+Space로 Microsoft 한국어 입력기로 바꿔 두세요. 윈도우는 고른 입력기만 앱에 불러들이므로 cssgsg가 게임에 들어가지 않습니다(게임 중에는 Win+Space를 누르지 마세요).
- 오른쪽 Alt·Ctrl을 보통 Alt·Ctrl로 쓰려면: 설정 → 시간 및 언어 → 언어 및 지역 → 한국어 옆 ⋯ → 언어 옵션 → 키보드 레이아웃 "레이아웃 변경" → 한글 키보드(101키) 종류 3 → 다시 시작.
- 지우기: 설정 → 앱 → 설치된 앱 → cssgsg. 설정과 학습(%APPDATA%\cssgsg, %LOCALAPPDATA%\cssgsg)은 남습니다.
