## 고친 것

- **Shift 탭으로 언어가 안 바뀌던 문제.** macOS 27에서 입력기가 받는 수식키 이벤트에는 좌우 구분 비트가 없고,
  같은 이벤트가 두 번씩 온다. 그래서 오른쪽 Shift가 "왼쪽 Shift를 쥔 채 누른 오른쪽 Shift"로,
  두 번째 이벤트가 "다른 키가 끼어듦"으로 읽혀 탭이 모두 사라졌다.
  이제 좌우는 키코드로 기억하고, 상태가 바뀐 이벤트만 쓴다(NRIME와 같은 방식).
  - 오른쪽 Shift 톡: 영어 ↔ 직전 언어(처음엔 한국어)
  - 왼쪽 Shift 톡: 한국어 ↔ 일본어

## 업데이트

메뉴 막대 cssgsg 메뉴 → 업데이트 확인 → "0.1.3 업데이트 설치…". 관리자 암호를 한 번 묻는다.
0.1.2부터는 설치가 끝나면 새 앱이 다시 뜬다(메뉴 첫 줄이 "cssgsg 0.1.3"이면 된 것).
