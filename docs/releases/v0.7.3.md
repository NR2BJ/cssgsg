## 0.7.2 설정 앱이 열리지 않던 문제를 고쳤습니다

- 0.7.2 설정 앱은 빌드한 맥에서만 열리고, 다른 맥에서는 열자마자 꺼졌습니다. 앱 안에 들어 있어야 할 설정 라이브러리를 빌드한 맥의 폴더에서 찾도록 잘못 빌드되었습니다. 입력기는 영향이 없었습니다.
- 설정 앱이 열리지 않는 맥에서는 설정 앱 안의 업데이트를 쓸 수 없습니다. 터미널에서 아래 명령으로 설치 파일을 받아 직접 설치해 주세요. 입력기를 지울 필요는 없습니다.

```
curl -fL -o ~/Downloads/cssgsg.pkg https://github.com/NR2BJ/cssgsg/releases/latest/download/cssgsg.pkg && open ~/Downloads/cssgsg.pkg
```

- 앞으로는 설치 파일을 만들 때 두 앱이 앱 밖의 라이브러리를 찾지 않는지 확인합니다.

## 업데이트

메뉴 막대 cssgsg → 설정… → 정보 탭 → 지금 확인 → 설치. 설정 앱이 열리지 않으면 위 명령으로 설치합니다.
