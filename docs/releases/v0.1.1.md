## 고친 것

- **설치한 뒤 입력 메뉴에 cssgsg가 안 나오던 문제.** 처음 실행 때 입력 모드만 켜고 입력기 본체는 켜지 않아서,
  입력 메뉴에도 시스템 설정의 추가(+) 목록에도 안 보였다. 이제 NRIME처럼 본체와 모드를 함께 켠다.
  0.1.0을 설치했다면 이 업데이트가 뜨면서 저절로 고친다(모드만 켜진 반쪽 상태일 때만 본체를 켠다. 직접 뺀 경우는 건드리지 않는다).

## 업데이트

메뉴 막대 cssgsg 메뉴(A / 한 / あ) → 업데이트 확인 → "0.1.1 업데이트 설치…". 관리자 암호를 한 번 묻는다.
메뉴가 안 보이거나 업데이트가 안 되면 처음 설치 명령을 다시 돌려도 된다:

```bash
curl -fL -o /tmp/cssgsg.pkg https://github.com/NR2BJ/cssgsg/releases/latest/download/cssgsg.pkg && sudo installer -pkg /tmp/cssgsg.pkg -target /
```

직접 추가할 때는 시스템 설정 → 키보드 → 입력 소스 → + → **영어(English)** 목록에 cssgsg가 있다.
