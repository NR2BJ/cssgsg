## 새로 생긴 것

- **일본어 한자 변환.** 가나를 치고 Space를 누르면 한자로 바뀐다(にほんご → 日本語, わたしのなまえは → 私の名前は).
  - 첫 Space는 가장 그럴듯한 결과만, 두 번째 Space부터 후보창이 뜬다. 1~9로 고르면 바로 확정, Enter는 확정, Esc는 취소.
  - ←→로 문절을 옮기고 Shift+←→로 문절 길이를 바꾼다.
  - 고른 것은 학습해서 다음에 먼저 나온다. 학습 기록은 `~/Library/Application Support/cssgsg/mozc`(NRIME의 Mozc와 따로).
  - 변환 엔진은 Mozc(구글 일본어 입력의 공개판)다. NRIME처럼 따로 도는 서버가 아니라 입력기 안에 들어 있어서,
    준비는 0.02초, 변환은 0.001초 안쪽이다.
- 앱에 오픈소스 고지문(`THIRD_PARTY_NOTICES.txt`)을 넣었다: Mozc, 사전 데이터(IPAdic 등), abseil, protobuf, zlib, Graphite, 新月.
- 설치 파일이 커졌다(사전 데이터 19MB).
