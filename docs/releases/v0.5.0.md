## 설정 앱을 다시 짰다

메뉴 막대 cssgsg 메뉴 → **설정…**. 바꾸면 입력기가 바로 적용한다(다시 시작 없음). 화면 언어는 한국어 · English · 日本語 중에서 고른다(정보 탭, 메뉴 막대 메뉴도 따른다).

### 일반

- **단축키 녹화(NRIME 방식):** 영어 ↔ 비영어, 한국어 ↔ 일본어, 한자 변환. 단추를 누르고 쓸 키를 누른다.
  - 수식키 하나만 톡 치면 탭(예: 오른쪽 Shift 탭), 수식키와 다른 키를 같이 누르면 조합(예: Option + Return)이다. 조합은 왼쪽·오른쪽 수식키를 가리지 않는다.
  - Esc는 취소, ✕는 없음, ↺는 기본값. 수식키 없는 글자·Space·Return 같은 키와, 이미 다른 곳에 쓰는 단축키는 받지 않는다.
  - 기본값은 그대로다: 오른쪽 Shift 탭, 왼쪽 Shift 탭, Option + Return. 0.4.0 설정 파일의 수식키 탭 설정은 그대로 옮겨진다.
- **빠른 탭 전환 보정(실험적, 기본 끔):** 탭 수식키를 떼기 전에 다음 글자를 눌러 버려도(겹침 허용 50ms 안) 전환하고 그 글자를 새 모드로 친다.
- **후보창 글자 크기**(10~28pt, 기본 14).
- **Electron 앱 Shift+Enter 대기**(기본 15ms, NRIME와 같다). 0.4.0에 보이던 120ms는 Codex처럼 Enter를 전송으로 받는 앱에만 쓰는 값이라 "고급"으로 옮겼다.

### 일본어

- **변환 키:** Space로 변환, Tab으로 변환을 따로 끈다(끈 키는 읽기를 확정한다. ↓는 늘 변환).
- **기호:** `\` 자리로 ¥ 치기(기본 켬, NRIME와 같다)를 더했다. "전각 스페이스"는 뜻이 보이게 이름을 바꿨다: 변환하지 않는 Space(읽기가 없을 때)로 전각 공백(　)을 친다.
- **개인 사전:** Mozc 사용자 사전을 이 탭에서 보고 넣고 고치고 지운다(읽기·단어·품사·메모, 찾기). 저장하면 바로 변환에 나온다.
- **변환 단축키 설명서**를 탭 맨 아래에 붙였다.

### 배열 학습

- 위의 참신세벌식 · Graphite · 新月 · 전환·공통 탭을 누르면 그 배열만 보인다. 0.4.0은 탭을 눌러도 안 가고 모든 배열이 한 페이지에 늘어섰다.

### 정보

- **업데이트는 여기서 한다.** 정식 · 베타 채널(베타는 시험판도 받는다), 지금 확인, 릴리스 노트, 설치. 탭을 열 때 하루 한 번 저절로 확인한다. 설치가 끝나면 입력기와 설정 앱이 다시 뜬다.
- 입력 소스 추가 여부, 키 보내기 권한(허용 안 됐으면 허용 단추), 화면 언어, 파일, 고지문.
