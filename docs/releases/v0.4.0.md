## 새 기능: 설정 앱

메뉴 막대 cssgsg 메뉴 → **설정…** 으로 연다. 바꾸면 입력기가 **바로** 적용한다(다시 시작하지 않아도 된다).

- **일반:** 수식키 탭으로 할 일(오른쪽·왼쪽 Shift, 그 밖의 Control·Option·Command), 탭 인식 시간, 모드 표시(G · ㅊ · 月) 켜기·자리, Codex류 앱의 Shift+Enter 줄바꿈 대기
- **한국어:** 배열(참신세벌식 v18 / D v19), 고른 한자 기억 지우기
- **일본어:** 구두점(、。 / ，． / ,.), / 자리 ・, 전각 스페이스, Caps Lock 가타카나(바로 확정, 모드를 나가면 끄기), Mozc 변환 학습 지우기
- **배열 학습:** 세 배열의 배열도와 규칙(메뉴의 "배열 학습…"도 이 탭을 연다)
- **정보:** 입력기·설정 앱 버전, 입력 소스에 추가했는지, 설정 파일·개발자 기록, 고지문

설정은 전처럼 `~/Library/Application Support/cssgsg/config.toml` 한 파일이다. 직접 고쳐도 되고, 고친 뒤 설정 앱을 열면 적용된다. 설정 앱이 쓰는 파일에는 설정마다 설명이 붙고, 기본값인 설정은 주석으로 남는다.

설정 앱(`cssgsgSettings.app`)은 입력기 옆(`/Library/Input Methods`)에 같이 설치된다. 메뉴의 "설정 파일 열기"는 설정 앱으로 옮겼다(정보 탭 → 설정 파일).

## 업데이트

메뉴 막대 cssgsg 메뉴 → 업데이트 확인 → "0.4.0 업데이트 설치…". 업데이트 뒤 메뉴에 "설정…"이 보인다.
