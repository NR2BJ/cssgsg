## 관리자 암호 창 Graphite를 고쳤습니다 (시험판)

- 0.7.5-beta.1은 Graphite 자판을 설치해 놓고도 찾지 못해서 관리자 암호 창이 그대로 쿼티였습니다. macOS가 자판에 붙이는 이름이 예상과 달랐습니다. 이제 설치된 자판을 제대로 찾아 끼웁니다.
- 나머지는 0.7.5-beta.1과 같습니다. 관리자 암호 창과 시스템 설정의 암호 확인 창에서 cssgsg를 쓰는 중이면 Graphite로 칩니다. 잠금 화면과 재부팅 직후 로그인 창은 아직 쿼티입니다.

## 확인 방법

cssgsg를 고른 상태에서 터미널에 아래 명령을 넣으면 관리자 암호 창이 뜹니다. 아무 글자나 몇 개 치고 취소하면, Graphite가 먹었는지 개발자 기록에 남습니다. 진짜 암호는 치지 않아도 됩니다.

```
osascript -e 'do shell script "true" with administrator privileges'
```

## 업데이트

시험판입니다. 설정 → 정보 탭의 채널이 베타면 받습니다.
