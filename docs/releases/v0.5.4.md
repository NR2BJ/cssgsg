## 줄바꿈 대기를 대기 시간 그대로 고릅니다

- **Shift+Enter 줄바꿈 대기 → Electron 앱**: 슬라이더 값이 곧 대기 시간입니다(5~100ms, 기본 15ms). 0.5.1~0.5.3의 "0 = 15ms에서 ±로 조정"하는 방식보다 알아보기 쉽게 바꿨습니다. 조합 중에 누른 ⌘ 단축키도 이만큼 기다렸다가 앱에 다시 보냅니다.
- **고급 → Codex**: Codex처럼 줄바꿈 글자를 넣으면 메시지를 보내 버리는 앱에서만 쓰는 값입니다(20~500ms, 기본 120ms). 위 값과 따로 쓰이고, 더하지 않습니다.
- 0.5.1~0.5.3에서 조정값을 바꿔 두었다면 같은 대기 시간으로 옮겨집니다.

## 화면 문구를 다듬었습니다

- 설정 앱의 설명을 "~합니다" 체로 바꾸고, 항목 이름은 NRIME처럼 짧은 명사형으로 정리했습니다. 한국어·영어·일본어 모두 손봤습니다.
- 변환 단축키 안내는 "입력 중 / 변환 중"으로 나누고, 설명도 "변환 시작", "변환 확정"처럼 짧게 바꿨습니다.
- 배열 학습 페이지, 설정 파일(config.toml)의 설명, 오류 메시지, 설치 화면 문구도 같은 말투로 바꿨습니다.
- macOS 27에서는 정보 탭의 권한 항목 이름이 시스템 설정과 같은 "기기 제어 및 데이터 접근"으로 표시됩니다(macOS 26 이하는 "손쉬운 사용").
