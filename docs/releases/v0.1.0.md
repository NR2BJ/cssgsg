cssgsg 첫 시험판. 참신세벌식(v18) · Graphite · 新月配列을 입력 소스 하나에서 쓰는 한/영/일 입력기다.

## 설치 (처음 한 번)

터미널에서 (관리자 암호를 묻는다):

```bash
curl -fL -o /tmp/cssgsg.pkg https://github.com/NR2BJ/cssgsg/releases/latest/download/cssgsg.pkg && sudo installer -pkg /tmp/cssgsg.pkg -target /
```

- 입력 메뉴에 cssgsg(ㅊ 아이콘)가 추가된다. 안 보이면 시스템 설정 → 키보드 → 입력 소스 → 편집에서 추가하거나, 로그아웃했다 다시 로그인한다.
- 전환: 오른쪽 Shift 톡 = 영어 ↔ 직전 언어, 왼쪽 Shift 톡 = 한 ↔ 일. 메뉴 막대에 A / 한 / あ로 보인다.
- 처음 실행 때 "손쉬운 사용" 권한을 한 번 묻는다. 없어도 입력은 된다(조합 중 ⌘/Option+키 재전송과 Codex 줄바꿈만 빠진다).
- 브라우저로 받은 pkg는 서명이 없어서 Gatekeeper가 막는다. 그때는 시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기".

## 업데이트

메뉴 막대 cssgsg 메뉴 → 업데이트 확인 (하루 한 번 저절로도 확인한다). 관리자 암호를 한 번 묻고, 로그아웃은 필요 없다.

## 들어 있는 것

- 참신세벌식 v18(기본)과 D v19(설정), Graphite, 新月配列. 단축키는 쿼티 자리 그대로.
- 모드 전환, 新月 Caps Lock 가타카나(일본어를 나가면 저절로 꺼짐), 조합 중 밑줄, 후보창, 비밀번호 칸은 쿼티.
- NRIME 우회책: ⌘/Ctrl/Option으로 조합을 확정한 뒤 키 재전송, Chromium 조합 중 Shift+Enter, 마우스 클릭 확정.
- 메뉴: 버전, 업데이트 확인, 배열 학습, 설정 파일(config.toml), 다시 시작.

## 아직 없는 것

모드 HUD, 설정 앱(학습 탭), 한자 변환, Mozc(일본어 후보는 지금 히라가나/가타카나뿐), 입력 소스 복구.
