## 게임 채팅에서 조합 중인 한글이 앞 글자에 겹치던 문제

- 오버워치처럼 IMM32로 글자를 받는 게임에서, 음절이 넘어갈 때(예: "안" 다음 "ㄴ") 확정한 글자와 새로 조합하는 글자를 한 번에 알리던 것을 Microsoft 한국어 입력기처럼 "확정 → 조합 끝 → 새 조합 시작" 순서로 나눠 알립니다. 게임이 확정한 글자를 다 받은 뒤에 새 조합을 시작합니다. 오버워치 채팅에서 조합 중인 글자가 입력칸 맨 앞에 겹쳐 그려지던 것이 이것 때문이라고 보고 고쳤습니다(VM의 시험 창에서는 Microsoft 입력기와 같은 모양이 됩니다. 오버워치에서 확인이 필요합니다).
- 메모장·카카오톡 같은 옛 Win32 앱과 게임 채팅에서 빠르게 칠 때, 조합 중 누른 띄어쓰기·Enter가 뒤에 친 글자 뒤로 밀리던 것을 고쳤습니다(예: "안녕 아"가 "안녕아 "로). 0.2.6에서 Space·Enter를 되살리며 생긴 문제입니다. 이제 키를 한꺼번에 쳐도 Microsoft 한국어 입력기와 같은 순서로 갑니다. 다시 보내는 키가 입력 장치를 거치지 않아서, 키 입력을 직접 읽는 게임에 Enter가 두 번 들어가지도 않습니다.

## 업데이트

- cssgsg 설정 → 정보 탭 → 지금 확인 → 설치. 받은 파일이 아래 SHA-256과 같을 때만 설치합니다(관리자 권한 창이 한 번 뜹니다).
- 이미 열려 있던 앱과 게임은 다시 열면 새 입력기를 씁니다.

## 설치와 지우기

- 처음 설치: 아래 cssgsg-setup.exe를 받아 실행한 뒤 Win+Space로 cssgsg(ENG)를 고릅니다.
- 코드 서명이 없습니다. 스마트 앱 컨트롤(Windows 보안 → 앱 및 브라우저 컨트롤)이 켜져 있으면 입력기가 뜨지 않습니다. SmartScreen이 막으면 "추가 정보 → 실행"을 누릅니다.
- 엄격한 커널 안티치트를 쓰는 게임(발로란트, 리그 오브 레전드, FACEIT 등)은 켜기 전에 Win+Space로 Microsoft 한국어 입력기로 바꿔 두세요. 윈도우는 고른 입력기만 앱에 불러들이므로 cssgsg가 게임에 들어가지 않습니다(게임 중에는 Win+Space를 누르지 마세요).
- 지우기: 설정 → 앱 → 설치된 앱 → cssgsg. 설정과 학습(%APPDATA%\cssgsg, %LOCALAPPDATA%\cssgsg)은 남습니다.
