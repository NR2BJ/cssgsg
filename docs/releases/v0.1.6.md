## 새로 생긴 것

- **모드 HUD.** Shift 톡으로 모드를 바꾸면 커서 근처에 A / 한 / あ가 1초쯤 떴다 사라진다(NRIME 표시기와 같다).
- **설정 파일에 `[mac]` 표.** 메뉴 막대 cssgsg 메뉴 → 설정 파일 열기에서 고치고 "cssgsg 다시 시작"을 누른다.
  - `hud = false`: HUD 끄기
  - `hud_position = "mouse"`: 커서 대신 마우스 옆에(커서 자리를 못 주는 앱에서도 뜬다)
  - `newline_replay_ms = 120`: Codex처럼 줄바꿈 입력을 전송으로 받는 앱에서 조합 중 Shift+Enter 뒤 줄을 바꾸기까지 기다리는 시간(20~1000).
    줄이면 빨라지지만 줄바꿈이 먹힐 수 있다.

## 업데이트

메뉴 막대 cssgsg 메뉴 → 업데이트 확인 → "0.1.6 업데이트 설치…". 0.1.5부터는 설치가 끝나면 cssgsg가 저절로 다시 뜬다.
