## 업데이트 확인을 자주 한다

- 설정 앱 정보 탭을 열 때마다 업데이트를 확인한다(1분 간격까지). 0.5.0~0.5.2는 하루 한 번만 확인해서, 그날 한 번 본 뒤에 나온 새 버전은 다음 날까지 "최신 버전이다"로 보였다.

## 다시 알림: 한국어로 시작

- 입력기를 켜거나 다시 시작하면 **ㅊ(한국어)** 로 시작한다(0.5.1부터). 0.5.0을 쓰고 있으면 이번 업데이트로 바뀐다.

## 0.5.0에서 바로 올라오면 같이 바뀌는 것

0.5.1·0.5.2의 변경(좌우를 가리는 조합 단축키와 왼쪽 Option + Return 한자 키, Control 한자 키 수정, ⌘ 조합 거부, ↓ 변환 키 삭제, 공백 반각/전각, ¥를 끄면 반각 `\`, 줄바꿈 대기 조정과 고급의 Codex 대기, 빠른 탭 전환 보정 보류, 배열 학습 미리 읽기, 모드 표시 글자 가운데)이 모두 들어 있다. 자세한 것은 0.5.1·0.5.2 릴리스 노트에 있다.

## 업데이트

메뉴 막대 cssgsg → 설정… → 정보 탭 → **지금 확인** → 설치. (0.5.0~0.5.2의 정보 탭은 하루 한 번만 확인하므로 "지금 확인"을 누른다.)
