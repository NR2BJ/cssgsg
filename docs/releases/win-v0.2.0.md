## Mozc 엔진 따로 업데이트, 작업 표시줄 아이콘 메뉴

- Mozc(일본어 변환 엔진)가 cssgsg와 따로 업데이트됩니다(맥과 같습니다). 엔진 호스트가 뜨고 5분 뒤, 그다음 하루 한 번 새 엔진이 있는지 보고 받아 둡니다. 엔진 호스트가 다시 시작할 때부터 씁니다. cssgsg 설정 → 일본어 → 변환 엔진에서 지금 확인하고 지금 적용할 수 있습니다.
  - 받은 엔진은 GitHub가 적은 SHA-256과 묶음 안 파일별 해시가 맞을 때만 씁니다. 읽지 못하거나 읽다가 멈춘 엔진은 다시 쓰지 않고 앞의 엔진으로 돌아갑니다.
  - 같은 Mozc라도 cssgsg 쪽 연결 코드(래퍼)만 고친 엔진을 새것으로 알아봅니다. 변환 엔진 칸에 "날짜, 래퍼 N"으로 보입니다.
- 작업 표시줄의 G · ㅊ · 月 아이콘을 누르면(왼쪽·오른쪽 모두) 맥의 메뉴 막대처럼 메뉴가 뜹니다: 영어 · 한국어 · 일본어, 설정…, 배열 학습, 타자 연습, 다시 시작.
  - 다시 시작은 엔진 호스트를 새로 띄웁니다. 받아 둔 새 Mozc 엔진도 이때 씁니다. 설정 앱 정보 탭의 다시 시작도 같습니다.
- 타자 연습 탭을 처음 열면 "여기를 누르면 이어서 칩니다"가 떠 있던 것을 고쳤습니다. 이제 바로 칠 수 있습니다.
- 정보 탭의 "로그인할 때 시작" 줄은 꺼져 있을 때만 보입니다.

## 업데이트

- 0.1.0에서: cssgsg 설정 → 정보 탭 → 지금 확인 → 설치. 받은 파일이 아래 SHA-256과 같을 때만 설치합니다(관리자 권한 창이 한 번 뜹니다).
- 이미 열려 있던 앱은 다시 열면 새 입력기(아이콘 메뉴)를 씁니다.

## 설치와 지우기

- 처음 설치: 아래 cssgsg-setup.exe를 받아 실행한 뒤 Win+Space로 cssgsg(ENG)를 고릅니다.
- 코드 서명이 없습니다. 스마트 앱 컨트롤(Windows 보안 → 앱 및 브라우저 컨트롤)이 켜져 있으면 입력기가 뜨지 않습니다. SmartScreen이 막으면 "추가 정보 → 실행"을 누릅니다.
- 엄격한 커널 안티치트를 쓰는 게임(발로란트, 리그 오브 레전드, FACEIT 등)은 확인되기 전까지 켜기 전에 Win+Space로 Microsoft 한국어 입력기로 바꿔 두세요.
- 게임 안의 후보창(UILess)과 게임 모드는 아직 없습니다.
- 지우기: 설정 → 앱 → 설치된 앱 → cssgsg. 설정과 학습(%APPDATA%\cssgsg, %LOCALAPPDATA%\cssgsg)은 남습니다.
