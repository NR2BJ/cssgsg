## 일본어 마지막 후보를 고를 수 있게 했습니다

- ﾆﾎﾝｺﾞ·ｲﾉﾁ 같은 반각 가타카나 후보(후보 목록의 맨 끝)가 Space나 방향키로 골라지지 않던 것을 고쳤습니다. 윈도우판을 만들다 찾은 Mozc 래퍼(cssgsg와 Mozc를 잇는 부분) 버그로, 앱에 든 엔진을 새로 빌드했습니다.

## Mozc 엔진 업데이트가 래퍼만 고친 엔진도 알아봅니다

- 같은 Mozc 버전이라도 래퍼를 고쳐 다시 빌드한 엔진을 새것으로 알아보도록 업데이트 확인을 고쳤습니다. 이런 엔진은 앞으로 래퍼 판을 달고 나옵니다.
- 설정 → 일본어 → 변환 엔진에 래퍼 판이 같이 보입니다(예: 3.34.6239.101 (2026-09-28, 래퍼 1)).

## 윈도우에서 쓴 설정 파일을 그대로 씁니다

- 설정 파일의 `[windows]` 표(윈도우판 설정)를 읽습니다. 0.7.1은 이 표를 몰라서 설정 전체를 기본값으로 읽었습니다.
- 맥 설정 앱에서 설정을 바꿔도 `[windows]`처럼 맥 설정 앱이 쓰지 않는 값을 지우지 않습니다.
- 설정 파일에 오류가 있을 때의 안내를 바로잡았습니다. 입력기는 기본 설정이 아니라 앞의 올바른 설정(처음이면 기본 설정)으로 동작합니다.

## 한자 단축키를 Control 탭으로 정했을 때

- Control을 누르는 순간 조합 중인 글자가 확정되어 한자로 바꿀 수 없던 것을 고쳤습니다.

## 바로잡음

- 0.7.1 릴리스 노트의 "타자 연습 탭에서 Shift가 모드를 바꾸지 않게 했습니다"는 맞지 않았습니다. 타자 연습 탭에서 Shift를 톡 누르면 모드가 바뀔 수 있습니다. 연습 판정은 누른 키의 자리로 하므로 결과에는 영향이 없습니다.
