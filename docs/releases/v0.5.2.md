## 줄바꿈 대기를 다시 나눴다

0.5.1의 "줄바꿈 대기 조정"은 값 하나로 Electron과 Codex 대기를 같이 움직였다. 그런데 Electron 대기(15ms)는 5ms 밑으로 내려가지 않아서, −10보다 낮게 하면 Codex 대기만 바뀌었다. 헷갈려서 다시 나눴다.

- **줄바꿈 대기 조정(−10 ~ +50ms, 기본 0):** Discord·Slack 같은 Electron 앱용이다. 기본 15ms에 더한다. −10이면 5ms로 가장 짧다. 옆에 지금 대기가 보인다. 조합 중 ⌘+키를 다시 보낼 때도 이 대기를 쓴다.
- **고급 → Codex 줄바꿈 대기(20 ~ 500ms, 기본 120):** Codex처럼 Enter를 전송으로 받는 앱에만 쓰는 따로 된 값이다(위 조정과 더하지 않는다). 알맞은 값을 실험으로 다시 찾는 중이라 넓게 열어 두었다.

0.5.1에서 조정값을 −10보다 낮게 해 두었으면 −10으로 읽는다. 그때 같이 바뀌었던 Codex 대기는 120으로 돌아간다.
