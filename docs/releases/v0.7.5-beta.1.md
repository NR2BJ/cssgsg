## 관리자 암호 창도 Graphite로 칩니다 (시험판)

- cssgsg를 쓰는 중이면 관리자 암호 창(설치·업데이트 때 뜨는 창)과 시스템 설정의 암호 확인 창에서도 Graphite로 칩니다. 0.7.4의 브라우저 비밀번호 칸과 합치면 대부분의 비밀번호를 Graphite로 칩니다.
- 이 창들은 입력기가 넣은 글자를 받지 않습니다. 그래서 그 창에서만 키보드 자판을 Graphite로 바꿔 끼웁니다. 이를 위해 Graphite 자판 파일을 함께 설치합니다(`/Library/Keyboard Layouts/cssgsg-Graphite.bundle`). 입력 소스에 추가할 필요는 없습니다.
- ⌘·Control·Option 단축키는 키캡(쿼티) 자리 그대로입니다.
- 잠금 화면과 재부팅 직후 로그인 창은 아직 쿼티입니다. 둘을 같이 바꿔야 같은 암호를 한 가지로 칠 수 있어서 다음 단계에서 함께 바꿉니다.

## 확인 방법

cssgsg를 고른 상태에서 터미널에 아래 명령을 넣으면 관리자 암호 창이 뜹니다. 아무 글자나 몇 개 치고 취소하면, Graphite가 먹었는지 개발자 기록에 남습니다. 진짜 암호는 치지 않아도 됩니다. 먹지 않았으면 로그아웃했다가 다시 해 봐 주세요.

```
osascript -e 'do shell script "true" with administrator privileges'
```

## 업데이트

시험판입니다. 메뉴 막대 cssgsg → 설정… → 정보 탭에서 채널을 베타로 바꾸면 받습니다.
