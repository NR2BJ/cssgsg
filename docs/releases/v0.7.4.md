## 브라우저 비밀번호 칸을 Graphite로 칩니다

- Safari, Chrome, Firefox(같은 엔진을 쓰는 브라우저와 Electron 앱 포함)의 비밀번호 칸에서는 지금 모드와 상관없이 Graphite로 칩니다. 윈도우판과 같습니다. 조합 밑줄은 없고, ⌘ 단축키는 키캡(쿼티) 자리 그대로입니다.
- 관리자 암호 창, 시스템 설정의 암호 확인처럼 시스템이 띄우는 인증 창은 아직 쿼티입니다. 이 창들은 입력기가 넣은 글자를 받지 않아서, 키보드 배열 자체를 바꾸는 다음 단계가 필요합니다.
- 비밀번호 칸에 글자가 들어가지 않는 브라우저나 앱이 있으면 알려 주세요. 그동안은 다른 입력 소스로 바꿔 치면 됩니다.
- 개발자 기록을 켜 두어도 비밀번호 칸에서 친 키는 남기지 않습니다. 0.7.3까지는 키 코드가 남았습니다.

## 메뉴 막대 메뉴를 윈도우판과 같게 했습니다

- 맨 위에서 영어·한국어·일본어 모드를 고릅니다(지금 모드에 체크). 다른 입력 소스를 쓰는 중이면 cssgsg로 바꿉니다.
- 설정… 아래에 배열 학습, 타자 연습을 두었습니다. 누르면 설정 앱이 그 탭으로 열립니다.

## 설정 창이 처음 열릴 때 끌리지 않던 문제

- 업데이트나 ⌘Q로 설정 앱을 끝낸 뒤 다시 열면 macOS가 앞의 창을 되살렸습니다. 되살린 창은 옮긴 자리도 저장되지 않았습니다. 이제는 늘 새 창으로 열고, 옮긴 자리와 크기는 다음에도 그대로입니다.
- 개발하는 맥에서는 창이 끌리지 않는 상황을 재현하지 못했습니다. 그래도 처음 연 창이 끌리지 않으면 어떻게 열었는지(업데이트 뒤, 메뉴, Finder) 알려 주세요.

## 업데이트

메뉴 막대 cssgsg → 설정… → 정보 탭 → 지금 확인 → 설치.
