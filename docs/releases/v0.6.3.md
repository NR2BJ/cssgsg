## Shift+Enter를 다시 보낼 앱을 설정에서 고칠 수 있습니다

- 줄바꿈 글자를 넣으면 메시지를 보내 버리는 앱(지금은 Codex)은 줄바꿈 글자 대신 Shift+Enter 키를 다시 받습니다. 이 목록은 코드에 들어 있어서, 이런 앱을 새로 찾으면 새 버전이 필요했습니다.
- 이제 **설정 앱 → 일반 → Shift+Enter를 다시 보낼 앱**에서 앱을 넣고 뺄 수 있습니다. "앱 추가…"로 응용 프로그램 폴더에서 고르고(여러 개 가능), −로 뺍니다. 기본은 Codex 하나입니다(앱 이름은 ChatGPT로 보입니다).
- 목록을 비우면 모든 앱에 줄바꿈 글자를 넣습니다.

## 줄바꿈 대기 이름과 범위를 정리했습니다

- 첫 번째 대기의 이름을 하는 일대로 **줄바꿈 넣기·⌘ 단축키**로 바꿨습니다. 웹 기술로 만든 앱의 줄바꿈뿐 아니라, 모든 앱에서 조합 중에 누른 ⌘ 단축키를 다시 보낼 때도 쓰입니다.
- 두 번째 대기는 **Shift+Enter 다시 보내기**입니다.
- 두 대기 모두 0~100ms로 맞췄습니다(기본값은 20ms, 50ms 그대로). 0.6.2에서 100ms보다 크게 해 두었다면 100ms로 읽습니다.
