## 옛 Win32 앱에서 한글 뒤 띄어쓰기·Enter가 사라지던 문제

- 메모장처럼 IMM32로 입력기를 쓰는 Win32 앱(카카오톡도 그럴 수 있습니다)에서, 한글을 조합하는 중에 Space나 Enter를 누르면 글자만 확정되고 띄어쓰기·줄바꿈이 사라지던 것을 고쳤습니다(예: "안 녕"을 치면 "안녕"). 0.1.0부터 있던 문제입니다. 이제 Microsoft 한국어 입력기와 같은 순서로 확정한 뒤 그 키가 앱에 갑니다. 게임 채팅에서 Enter로 보낼 때 마지막 글자가 빠지지 않습니다.
- 게임(오버워치 등)에서 모드 표시(G·ㅊ·月)가 모니터 오른쪽 아래에 뜨던 것을 고쳤습니다. 게임이 입력 자리를 화면 구석으로 알려 주던 것이라, 구석 자리는 쓰지 않습니다.
- 아직 남은 것: 오버워치에서 조합 중인 한글이 입력칸 맨 앞에 겹쳐 그려지는 것. Microsoft 입력기도 오버워치에서는 표시가 어긋나서 원인을 더 보고 있습니다.

## 업데이트

- cssgsg 설정 → 정보 탭 → 지금 확인 → 설치. 받은 파일이 아래 SHA-256과 같을 때만 설치합니다(관리자 권한 창이 한 번 뜹니다).
- 이미 열려 있던 앱과 게임은 다시 열면 새 입력기를 씁니다.

## 설치와 지우기

- 처음 설치: 아래 cssgsg-setup.exe를 받아 실행한 뒤 Win+Space로 cssgsg(ENG)를 고릅니다.
- 코드 서명이 없습니다. 스마트 앱 컨트롤(Windows 보안 → 앱 및 브라우저 컨트롤)이 켜져 있으면 입력기가 뜨지 않습니다. SmartScreen이 막으면 "추가 정보 → 실행"을 누릅니다.
- 엄격한 커널 안티치트를 쓰는 게임(발로란트, 리그 오브 레전드, FACEIT 등)은 켜기 전에 Win+Space로 Microsoft 한국어 입력기로 바꿔 두세요. 윈도우는 고른 입력기만 앱에 불러들이므로 cssgsg가 게임에 들어가지 않습니다(게임 중에는 Win+Space를 누르지 마세요).
- 지우기: 설정 → 앱 → 설치된 앱 → cssgsg. 설정과 학습(%APPDATA%\cssgsg, %LOCALAPPDATA%\cssgsg)은 남습니다.
