## 바뀐 것: 한국어 한자는 조합 중인 글자 하나만 바꾼다

- 0.3.0은 Option+Return을 누르면 앞 글자까지 묶어 낱말(大韓民國)로 바꿨는데, Discord 같은 Electron·Chrome 계열 앱에서 앞 글자가 지워지지 않고 "대한민大韓民國"처럼 겹쳤다.
- 이제 **조합 중인 글자 하나만** 바꾼다: 대한민 + 국 → Option+Return → 대한민國. 앞 글자는 건드리지 않으므로 어느 앱에서나 같다.
- 조합 중인 글자가 없으면 Option+Return은 앱으로 간다(0.2.x와 같다). 선택한 글 바꾸기도 뺐다.
- 한자가 없는 음절(뭐 등)에서는 Option+Return이 아무것도 하지 않는다(메신저에서 줄바꿈·전송이 되지 않게).
- 후보 옆 뜻(國 나라 국), 기호표(자음 하나 + Option+Return), 고른 한자 기억, 후보창 조작은 그대로다.
