## 처음 내는 윈도우판입니다

맥과 같은 코어로 참신세벌식(한국어) · Graphite(영어) · 新月(일본어)를 칩니다. x64, 윈도우 10 1809 이상과 윈도우 11에서 돕니다.

- 모드 전환: 오른쪽 Shift 톡은 영어 ↔ 비영어, 왼쪽 Shift 톡은 한국어 ↔ 일본어(맥과 같습니다). 작업 표시줄에 G · ㅊ · 月이 보이고, 바꿀 때 커서 위에 잠깐 뜹니다.
- 한국어 한자: 조합 중인 글자에서 오른쪽 Ctrl 톡(한국 키보드의 한자 키 자리)을 누릅니다. 맥 기본값인 왼쪽 Option(Alt)+Return은 윈도우에서는 앱 메뉴가 Alt를 먼저 가져가서 쓸 수 없습니다.
- 일본어 한자 변환: 맥과 같은 Mozc를 씁니다. 로그인할 때 엔진 호스트(cssgsg-host.exe, 메모리 20MB 안팎)가 떠서 모든 앱의 변환을 맡습니다.
- 비밀번호 칸(브라우저 등)은 모드와 상관없이 Graphite로 칩니다(맥보다 앞섭니다). 단축키는 키캡(쿼티) 자리 그대로입니다.
- 설정 앱: 시작 메뉴 → cssgsg 설정. 맥과 같은 탭(일반 · 한국어 · 일본어 · 배열 학습 · 타자 연습 · 정보)이고, 바꾼 설정은 글자를 치던 앱으로 돌아가면 적용됩니다. 맥의 Shift+Enter 줄바꿈 대기는 윈도우에서는 필요 없어서 없습니다. 단축키에 Alt와 Windows 키는 쓸 수 없습니다.

## 설치

아래 cssgsg-setup.exe를 받아 실행합니다(관리자 권한 창이 한 번 뜹니다). 끝나면 Win+Space를 눌러 입력기 목록에서 cssgsg(ENG)를 고릅니다. 이미 열려 있던 앱은 다시 열면 새 입력기를 씁니다.

- 코드 서명이 없습니다. 스마트 앱 컨트롤(Windows 보안 → 앱 및 브라우저 컨트롤)이 켜져 있으면 입력기가 뜨지 않습니다. SmartScreen이 막으면 "추가 정보 → 실행"을 누릅니다.
- 엄격한 커널 안티치트를 쓰는 게임(발로란트, 리그 오브 레전드, FACEIT 등)은 확인되기 전까지 켜기 전에 Win+Space로 Microsoft 한국어 입력기로 바꿔 두세요(입력기 DLL이 게임에 들어가지 않습니다).
- 게임 안의 후보창(UILess)과 게임 모드는 아직 없습니다.

## 업데이트와 지우기

- 업데이트: cssgsg 설정 → 정보 탭 → 지금 확인 → 설치. 받은 파일이 아래 SHA-256과 같을 때만 설치합니다. Mozc 엔진도 같이 업데이트됩니다.
- 지우기: 설정 → 앱 → 설치된 앱 → cssgsg. 설정과 학습(%APPDATA%\cssgsg, %LOCALAPPDATA%\cssgsg)은 남습니다.
