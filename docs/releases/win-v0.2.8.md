## 한국어 입력기로 바뀝니다

- cssgsg가 윈도우에서 영어(미국) 입력기가 아니라 한국어 입력기로 등록됩니다. Win+Space 목록에 "한국어 cssgsg"로 나옵니다. 업데이트한 뒤 Win+Space로 한 번 골라 주세요.
- 까닭: 오버워치처럼 입력 언어가 한국어일 때만 한글 조합을 제자리에 그리는 게임이 있습니다. 0.2.7까지 오버워치 채팅에서 조합 중인 글자가 입력칸 맨 앞에 겹쳐 그려진 것이 이 때문으로 보입니다. 이제 게임이 보는 입력 언어와 입력기 정보가 Microsoft 한국어 입력기와 같습니다(오버워치에서 확인이 필요합니다). 일본어(新月)는 Microsoft 일본어 입력기도 오버워치에서 겹쳐 그려져서 게임 쪽 한계로 봅니다.
- 달라지는 키: 오른쪽 Alt·Ctrl이 Microsoft 한국어 입력기를 쓸 때처럼 한/영·한자 키가 됩니다(윈도우의 한국어 키보드 종류 설정에 따라 자리가 바뀔 수 있습니다). 한/영 키는 영어 ↔ 방금 쓰던 한국어·일본어 전환, 한자 키는 한자 변환입니다. Shift 톡 전환, 왼쪽 Alt·Ctrl은 그대로입니다.
- 업데이트하면 영어(미국) 쪽 cssgsg는 목록에서 빠집니다. 영어(미국)에 다른 키보드가 없었으면 영어(미국) 언어도 목록에서 빠집니다(윈도우 표시 언어가 영어면 남습니다).

## 크로미움 앱에서 Enter가 빠지던 문제

- 0.2.6~0.2.7에서 Edge·Chrome·VS Code·Discord 같은 크로미움 기반 앱에서 한글을 조합하는 중에 Enter를 누르면 줄바꿈이 빠지고, 빠르게 치면 띄어쓰기·줄바꿈이 뒤로 밀리던 것을 고쳤습니다. 메모장 같은 옛 Win32 앱을 위한 처리를 크로미움 앱에도 하고 있었습니다.

## 옛 Win32 앱

- 메모장 같은 옛 Win32 앱과 게임 채팅에 한글 조합 글자를 Microsoft 한국어 입력기처럼 보냅니다. 한국어 입력기가 되면서 필요해졌습니다(그러지 않으면 메모장이 자모를 낱자로 확정했습니다).

## 업데이트

- cssgsg 설정 → 정보 탭 → 지금 확인 → 설치. 받은 파일이 아래 SHA-256과 같을 때만 설치합니다(관리자 권한 창이 한 번 뜹니다).
- 이미 열려 있던 앱과 게임은 다시 열면 새 입력기를 씁니다.

## 설치와 지우기

- 처음 설치: 아래 cssgsg-setup.exe를 받아 실행한 뒤 Win+Space로 한국어 cssgsg를 고릅니다.
- 코드 서명이 없습니다. 스마트 앱 컨트롤(Windows 보안 → 앱 및 브라우저 컨트롤)이 켜져 있으면 입력기가 뜨지 않습니다. SmartScreen이 막으면 "추가 정보 → 실행"을 누릅니다.
- 엄격한 커널 안티치트를 쓰는 게임(발로란트, 리그 오브 레전드, FACEIT 등)은 켜기 전에 Win+Space로 Microsoft 한국어 입력기로 바꿔 두세요. 윈도우는 고른 입력기만 앱에 불러들이므로 cssgsg가 게임에 들어가지 않습니다(게임 중에는 Win+Space를 누르지 마세요).
- 지우기: 설정 → 앱 → 설치된 앱 → cssgsg. 설정과 학습(%APPDATA%\cssgsg, %LOCALAPPDATA%\cssgsg)은 남습니다.
