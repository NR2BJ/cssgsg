## 설정 앱에 타자 연습 탭을 넣었습니다

- 참신세벌식 v18, Graphite, 新月을 단계별로 익히는 타자 연습입니다. 메뉴 막대 cssgsg → 설정… → 타자 연습 탭에서, 창을 키우거나 전체 화면으로 쓰면 됩니다.
- 단계마다 자리 익히기 → 낱말 치기 → 줄 치기 순서입니다.
  - 참신세벌식: 받침 없이 홈열 → 윗열 → 아랫열 → ㅑ·겹모음·된소리, 받침도 같은 순서, 그다음 규칙(왼손·오른손 ㅗ·ㅜ, 문장부호, 자음만 칠 때 ❖)과 실전입니다.
  - Graphite: 손가락별로 두세 글자씩 더하고, 대문자와 기호, 실전입니다.
  - 新月: 한 번에 치는 가나 → ゛ → ☆ 다음 왼손 → ★ 다음 오른손 → 요음·작은 글자 → 3타 줄임 → 기호, 실전입니다. 한자가 섞인 글을 보고 읽기(가나)를 칩니다.
- 점수나 속도는 없습니다. 틀린 키는 넘어가지 않고, 틀린 것은 판 끝에 한 번 더 나오며, 자주 틀리는 키가 든 글자가 더 자주 나옵니다. 모르는 키는 누르지 말고 1초 기다리면 자리를 보여 줍니다.
- 권장 입력을 보여 주고, 원작자가 허용하는 다른 입력(된소리 연타, 표준 순서 겹받침 등)도 받습니다. 치는 방법과 연습 글은 모두 입력기 엔진으로 확인했습니다.
- 연습 화면에는 입력칸이 없어 입력기가 끼지 않습니다. 입력 소스는 무엇이든 괜찮습니다.
- 기록(끝낸 단계, 자주 틀린 키, 고른 단계)은 설정 파일 옆 `practice.json`에 남습니다(정보 탭 → 파일 → 타자 연습 기록).
